Current release

Version 1.0.1

The article reader now loads on demand when an X tab was opened before the extension was installed. You can create a PDF without manually reloading that tab.

Save long-form X Articles in a two-column, Letter-size layout with 9 pt Times New Roman body text. Article processing stays local.

Update a local installation.

  1. Download and extract the new release ZIP.
  2. Replace the contents of your existing installed x-to-pdf folder with the new files.
  3. Open chrome://extensions and click Reload for X to PDF.
  4. Refresh open X Article tabs before using the updated extension.

Updates to ZIP installations are manual. Keep the installed folder in its permanent location.
